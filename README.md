## Featured Projects

### ☁️ [SmartTask](https://github.com/cristinalacovei/smarttask)

**Cloud-native task management and AI study-planning platform**

[🚀 Live Demo](https://d28ry4mculifvr.cloudfront.net)

SmartTask is a full-stack microservices application built with Spring Boot, Spring Cloud, Angular, Keycloak, Docker, and AWS.

Highlights:

- Spring Boot microservices
- Netflix Eureka service discovery
- Spring Cloud API Gateway
- OAuth2 / OpenID Connect with Keycloak
- Authorization Code + PKCE for the frontend
- OAuth2 Client Credentials for machine-to-machine communication
- role-based authorization and backend task ownership validation
- PostgreSQL on Amazon RDS
- AI Study Planner using Spring AI + Google Gemini
- Dockerized services deployed on ECS Fargate
- S3 + CloudFront frontend hosting
- AWS Secrets Manager and CloudWatch
- automated AWS CI/CD with CodePipeline + CodeBuild + ECR + ECS

**Tech:** Java 21 · Spring Boot · Spring Cloud · Angular · TypeScript · PostgreSQL · Keycloak · Docker · AWS · Spring AI · Gemini
